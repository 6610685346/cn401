Database (PostgreSQL) - optional, see DATABASE.md

without DATABASE_URL everything stays as before: faces in output/people.json, history in CSV.
with it, faces go to persons/face_embeddings and every logged person is a row in detection_logs
(the CSV is still written as a backup while SAVE_CSV is on).
1. install Docker Desktop, then in this folder:
     set DB_PASSWORD=pick-a-password
     docker compose up -d
2. tell the program where the database is (setx keeps it for new windows, incl. "CN401 App.bat"):
     setx DATABASE_URL "postgresql+psycopg://postgres:pick-a-password@localhost:5432/person_detection"
   close this window and open a new one
3. .venv\Scripts\activate  then  pip install -r requirements.txt   (adds SQLAlchemy + psycopg)
4. cd new
     python register.py init            create the tables
     python register.py import-people   copy output/people.json in (optional)
     python register.py import-csv      copy the old CSV history in (optional, safe to repeat)
     python register.py status          check
5. start the app: its first page says "บันทึกลง PostgreSQL"
other commands: python register.py list | delete NAME | purge --days 90
in/out counting: tick "บอกทิศทางเดินผ่านโซน" on a camera; rows get direction in/out
(swap DIRECTION_NAMES in config.py if in and out come out reversed)


Desktop app (V02) - main program

double-click "CN401 App.bat"   (or setup_and_run.bat -> menu 1)
everything is in the app window: IP cameras, this computer's camera, people,
floor calibration, floor map, history, settings, user accounts (ผู้ดูแล).
cameras record while the app is open (minimise is fine, closing stops them).
log file: logs/app.log
desktop shortcut: setup_and_run.bat -> menu 6


Web (LAN) - history only

the app also serves https://<this computer's IP>:8000/ for other computers:
log in, read and download the history. nothing else is on the web.
make accounts in the app: ผู้ดูแล -> Users -> Add.
app closed?  setup_and_run.bat -> menu 5  (history page only)

GPU (NVIDIA) - do this once

pip install -r requirements.txt gives the CPU build of PyTorch on Windows: it works, but slowly
(the app's first page then says "CPU (ไม่พบ CUDA)"). To use the graphics card:
1. open https://pytorch.org/get-started/locally/ and pick Stable / Windows / Pip / Python /
   the CUDA version your driver supports (see: nvidia-smi)
2. open Command Prompt in this folder and run  .venv\Scripts\activate
3. run the command from that page, adding  --force-reinstall  and the versions from
   requirements.txt:  torch==2.14.1 torchvision==0.29.1
4. start the app again: the first page should show the graphics card name
